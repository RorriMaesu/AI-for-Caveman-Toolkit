# Chapter 2: The Spirit Tongue (Vibe Coding)

**"Nerak was wrong. Power is not in the tongue. Power is in wish."**

This chapter teaches you how to stop typing every line of code manually and start "Vibe Coding"—telling the AI what you want, and letting it write the Python for you.

## Files
- **`vibe_check.py`**: The result of the "Vibe Check" challenge. This script uses `psutil` to scan your computer's "Spirit Strength" (RAM/CPU) so you know if you can run local AI.

## The Grug Workflow
1.  **The Grunt (Prompt):** Explain the goal in plain English.
2.  **The Spirit's Song (Generation):** Let VS Code + Copilot write the code.
3.  **The Test:** Run it.
4.  **The Fix:** Paste errors back to the AI.

## Setup
To run the script here, you need `psutil`:
```bash
pip install psutil
```
