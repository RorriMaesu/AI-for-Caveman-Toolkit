# AI For Caveman - Official Code Repository

Welcome, Hunter. This is the Cave Wall where we keep the tools.

## How to Use
1. **Find your Chapter.** The folders match the book chapters.
2. **Don't Copy/Paste.** Use the "Vibe Coding" prompts in the book to ask your AI to write these scripts for you.
3. **Compare.** Use the files here to check if your AI did a good job.
